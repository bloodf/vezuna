Vezuna organiza perfiles familiares, informes de laboratorio, horarios de medicamentos y exportaciones en tu dispositivo. No necesitas crear una cuenta en la app.

> **Preparación para el lanzamiento:** todavía no se ha publicado una versión estable. Las compilaciones firmadas, la entrega de modelos, las pruebas físicas y la revisión de las tiendas siguen pendientes. Vezuna no diagnostica enfermedades, no recomienda tratamientos ni modifica dosis.

## Guía esencial

Lee [Primeros pasos](/es/docs/getting-started) para crear un perfil ficticio, importar y revisar un informe y entender permisos, copias de seguridad y soporte.

La [documentación completa en inglés](/docs) también incluye guías de laboratorio, medicamentos, privacidad, modelos sin conexión y desarrollo nativo.

## Soporte seguro

Para preguntas de privacidad o problemas generales, utiliza las [issues de GitHub](https://github.com/bloodf/vezuna/issues). Para vulnerabilidades, selecciona **Security → Report a vulnerability** en el repositorio.

Nunca subas informes médicos, recetas, capturas de registros, archivos del almacenamiento ni copias de seguridad reales. Utiliza únicamente datos fictícios. El proyecto se mantiene con el mejor esfuerzo, sin compromiso de tiempo de respuesta. Consulta [Soporte](/es/support).
