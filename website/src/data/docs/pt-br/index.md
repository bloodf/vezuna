O Vezuna organiza perfis da família, exames laboratoriais, horários de medicamentos e exportações no seu dispositivo. Não é necessário criar uma conta no app.

> **Preparação para lançamento:** ainda não há uma versão estável publicada. Builds assinados, entrega de modelos, testes em dispositivos físicos e análise das lojas continuam pendentes. O Vezuna não diagnostica doenças, não recomenda tratamentos e não altera doses.

## Guia essencial

Leia [Primeiros passos](/pt-br/docs/getting-started) para criar um perfil fictício, importar e revisar um exame, entender permissões, backups e obter suporte.

A [documentação completa em inglês](/docs) também contém guias de registros laboratoriais, medicamentos, privacidade, modelos offline e desenvolvimento nativo.

## Suporte seguro

Para dúvidas sobre privacidade ou problemas comuns, use as [issues do GitHub](https://github.com/bloodf/vezuna/issues). Para vulnerabilidades, abra **Security → Report a vulnerability** no repositório.

Nunca envie exames, receitas, capturas de registros, arquivos do cofre ou backups reais. Use somente dados fictícios. O projeto é mantido com melhor esforço, sem compromisso de tempo de resposta. Veja [Suporte](/pt-br/support).
