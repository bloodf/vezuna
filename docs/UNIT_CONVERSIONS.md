# Unit conversions

Display-only conversions used by trends and result detail. Stored values and units are never rewritten: the value as entered is always shown, and a converted figure appears only when this table has a factor for that analyte and that pair of units. Without a factor, results in another unit are listed as not shown, never silently dropped or guessed.

The table lives in `shared/src/commonMain/kotlin/app/vezuna/domain/AnalyteConversions.kt`, one entry per row below, each with its citation. `AnalyteConversionsTest` checks every factor against its published value and, for mass-to-molar factors, against `10 / molar mass`. The maintainer reviews this table before merge.

Formula: `value[from] x factor = value[to]`. The inverse conversion divides by the factor.
